3. 유사 도메인 경험

  • 사용자 제보·후기 시스템: 모든별키즈(대한민국 No.1 아동 발달 매칭 플랫폼)에서 보호자 후기/문의 접수, 관리자 모더레이션, 알림 발송 직접 구축
  • 카카오 알림톡/SMS 연동: 다수 서비스에 비즈톡 API + 발신 프로필 관리 적용
  • reCAPTCHA · 다중 이미지 압축: 표준 적용 패턴 보유
  • 개인정보 처리 흐름: 비회원 제보의 동의/암호화/접근 로그 구조 운영 경험
