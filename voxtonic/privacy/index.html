Privacy Policy

Voxtonic (Android) · Effective date: May 21, 2026 · Last updated: May 21, 2026

Summary

The Voxtonic Android app ("the App") performs text-to-speech on your device. The developer does not operate a backend server for the App and does not have a user account system.

The App makes outbound network requests only in three situations described in Section 4: downloading the AI model files from Hugging Face, serving advertisements via Google AdMob, and (only if you open the Voice Builder screen) loading a web page hosted by Supertone.

1. Identity of the developer

The App is published by an independent developer, GwonHyeok, under the brand GHPlanet.

Contact: me@ghyeok.io

2. Personal information the developer collects

The developer does not operate any server or analytics system that receives personal information from the App. The App contains no sign-in or account feature and no analytics SDK operated by the developer. The developer has no database of users.

This means the developer does not receive, store, or transmit:

  • Your name, email, phone number, or any account identifier.
  • The text you enter into the App.
  • Voice recordings you make or import as references.
  • Audio files the App synthesizes.

Third-party services embedded in the App do collect data on their own; those are described in Section 4.

3. Data stored on your device

The following data is written to the App's private storage on your device. It is not uploaded by the App's own code.

  • Prompt text and synthesized WAV files — saved to the App's private files directory so they appear in the Library tab.
  • Voice reference recordings or imported audio — saved to the App's private files directory and used to compute a voice embedding for on-device synthesis.
  • Preferences — selected language, selected voice, onboarding state, stored via Android SharedPreferences.
  • AI model files — downloaded once on first run (see Section 4.2) and cached in the App's files directory.

You can delete this data by removing items individually inside the App, by using Android Settings → Apps → Voxtonic → Storage → "Clear storage", or by uninstalling the App.

4. Third-party services and network requests

4.1 Google AdMob — advertising

The App displays banner, interstitial, and native ads supplied by Google AdMob (Google LLC). When ads are requested, the Google Mobile Ads SDK communicates directly with Google. The data Google collects and how it uses it are described in Google's own policies linked below; typical data points published by Google for AdMob include the Android Advertising ID, IP address, device model and OS version, and ad interaction events.

The developer has not enabled impression-level user data in the AdMob console and has not added any additional mediation networks; the developer's view of this data is limited to the aggregated reports Google provides in the AdMob console.

References:

  • Google Privacy Policy
  • How Google uses information from sites or apps that use our services
  • AdMob & AdSense data disclosure

4.2 Hugging Face — model file download

On first launch, the App downloads the Supertonic 3 ONNX model files over HTTPS from huggingface.co. This download is required for on-device synthesis to function. The App's code does not attach any user identifier, cookie, or token to this request; the standard request metadata visible to any HTTPS server (such as IP address and user agent) is visible to Hugging Face. See the Hugging Face Privacy Policy.

4.3 Supertone — embedded Voice Builder web page

The App contains a "Voice Builder" screen that loads https://supertonic.supertone.ai/voice-builder in an in-app web view. This request is only made if you navigate to that screen. Any data handling on that page is governed by Supertone's own terms and privacy policy, not by this policy. See supertone.ai for their policies.

4.4 No other outbound network calls

Aside from the three services above, the App's own code makes no other outbound network calls.

5. Permissions requested by the App

6. Children

The App is not designed for, or directed to, children under the age of 13 (or the equivalent minimum age in your jurisdiction). The developer does not knowingly collect any information from children. If you believe a child has used the App in a way that should be addressed, contact me@ghyeok.io.

7. Your rights

Because the developer does not store personal information about you on systems the developer controls, requests to access, correct, or delete personal information held by the developer typically have no responsive data.

To delete data stored locally by the App, use Android Settings → Apps → Voxtonic → Storage → "Clear storage", or uninstall the App.

For data handled by Google AdMob, exercise the controls described by Google at the links in Section 4.1, and use Android Settings → Privacy → Ads to reset or delete your advertising ID and to opt out of ad personalization.

For data handled by Hugging Face or Supertone when their endpoints are contacted from the App, refer to their privacy policies linked in Sections 4.2 and 4.3.

8. International transfers

No personal data flows to the developer's own infrastructure, because the developer does not operate any. Third-party services contacted by the App (Google, Hugging Face, Supertone) operate internationally and may process requests in countries other than your own; refer to their privacy policies for the specifics.

9. Security

Data stored by the App stays in the App's private storage, which Android isolates from other applications. Network requests made by the App use HTTPS.

10. Changes to this policy

If the App's data practices change in a material way — for example, if a new third-party SDK is added or if a new permission is requested — this page will be updated and the "Last updated" date at the top will be revised.
