AI 기반 생체 이미지 파이프라인 PoC 개발

제안자 권혁 (10년차 풀스택) 제안 19,000,000원 기간 120일 도메인 점술/관상 — SoulTalk(국내 1위) 운영자

1. 한 줄 요약

손바닥 이미지에서 키포인트·길이 비율을 실제로 추출하는 PoC를 제안서 작성 단계에서 미리 구현해두었습니다. 아래 데모에서 본인의 손 사진을 업로드하시면 21개 키포인트 검출 + 검지/중지 길이 비교가 브라우저에서 즉시 실행됩니다. 이미지는 어디에도 전송되지 않고 브라우저 내에서만 처리됩니다.

2. 인터랙티브 데모 — 직접 손 사진을 올려보세요

손바닥 키포인트 추출 PoC · MediaPipe Hands Live
대기 중. 모델은 첫 추론 시 자동 로드됩니다 (약 5MB).

위 데모는 본 PoC의 첫 단계인 손 영역 인식 + 21개 키포인트 추출까지를 그대로 보여드립니다. 실제 PoC에는 여기에 손금 선 검출(엣지)·점/마커 검출(블롭)·공식 대입 엔진이 추가됩니다.

3. 도메인 적합도

국내 1위 타로·사주·신점 앱 SoulTalk을 제가 Flutter + 백엔드 전 과정 단독으로 구축·운영했습니다. 사주·타로·관상 등 점술 결과 도출 로직, 사용자 입력에서 텍스트 결과로 풀어내는 흐름, 대규모 트래픽 안정화까지 본 프로젝트의 결과 산출 파트와 직접 연결됩니다.

본 PoC는 헬스케어가 아닌 관상/손금의 IT 구현이라는 점에서 일반 ML 엔지니어보다 도메인 운영 경험자가 텍스트 풀이 톤·결과 표현 방식 합의를 빠르게 끌어낼 수 있다고 판단합니다.

4. 기술 스택 제안

레이어스택역할
키포인트 검출MediaPipe Hands / OpenCV21개 landmark 추출, 손가락 영역 분리
특징 추출NumPy + OpenCV길이 비율, 손금 선(엣지 디텍션), 점(블롭 디텍션)
공식 엔진Python 규칙 엔진고객사 제공 공식을 JSON DSL로 정규화
배치 파이프라인Celery / Argo / 또는 단순 큐14만 장 분산 처리 + 재시도 + 정합성 검증
관리자 웹Next.js + FastAPI이미지 업로드 → 추출 시각화 → 결과 텍스트 확인
인프라AWS / GCPGPU는 학습 단계만 사용. 추론은 CPU + 서버리스 비용 최적화

5. 14만 장 처리 아키텍처

┌──────────────┐    ┌────────────────────┐    ┌──────────────┐    ┌──────────────┐
│ 원본 이미지   │ →  │ 전처리 + Hands 검출  │ →  │ 특징 JSON     │ →  │ 공식 엔진     │
│ 14만 장 (S3)  │    │ 손 영역, 21 keypoint │    │ 비율/선/점    │    │ 결과 텍스트   │
└──────────────┘    └────────────────────┘    └──────────────┘    └──────────────┘
                                 ↓
                      [실패 케이스 격리 + 재시도 큐]
                                 ↓
                        정합성 검증 → 관리자 시각화
  • 실패 케이스(손 미검출, 흐림 등)는 별도 큐로 분리해 모델 보강 데이터로 활용
  • 각 단계 결과는 중간 저장 (장애 시 해당 단계부터 재실행)
  • 관리자 웹에서 무작위 샘플링하여 특징 추출 정합성 직접 확인 가능
