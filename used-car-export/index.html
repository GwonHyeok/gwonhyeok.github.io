K-Car 차량 데이터 연동 기술 분석

해외 바이어 대상 중고차 수출 플랫폼 MVP 구축 — K-Car 외부 데이터 연동의 기술적 가능성, 응답 데이터 품질, 운영·법적 리스크를 실측으로 검증한 보고서입니다.

제안자 권혁 (10년차 풀스택) 분석일 2026-05-21 대상 kcar.com 공개 웹 트래픽 방법 정상 브라우징 + 클라이언트 JS 정적 분석
이 문서의 위치: 입찰 단계에서 클라이언트가 K-Car 데이터 연동의 실제 가능성을 판단할 수 있도록 작성된 기술 실측 보고서입니다. 본 보고서는 운영 단계에서 비공식 채널 직접 호출을 권장하지 않으며, 최종 권고안은 §9. 운영 권고에서 확인하실 수 있습니다.

1. 한줄 요약

기술적으로는 100% 가능합니다. K-Car 사이트는 자사 프론트엔드(www.kcar.com)에서 단일 백엔드(api.kcar.com)로 호출하는 8개의 핵심 API로 구성돼 있고, 차량 검색만 가벼운 난독화(AES-128, 키·IV 클라이언트 하드코딩)가 적용되어 있으며, 응답은 모두 평문 JSON입니다. 차량당 VIN·사고이력·부품별 진단·360° 이미지 72장까지 전부 받을 수 있습니다.

다만 운영 단계에서는 권장하지 않습니다. 약관·DB권·개인정보·키 로테이션 리스크가 비즈니스 지속성을 위협합니다. 견적은 (A) 공식 제휴 연동 또는 (B) 관리자 수동 등록 두 트랙으로 분리해 제안합니다.

2. 검증 방법

  1. 정상 브라우징으로 트래픽 캡처 — Chrome DevTools로 실제 사용자처럼 검색 → 차량 상세 진입했을 때 사이트가 자체적으로 호출하는 모든 API 응답을 기록
  2. Nuxt 빌드 청크 정적 분석 — /_nuxt/*.js 9개 청크를 다운로드해 enc/AES/drct 키워드로 grep, 검색 API 페이로드 암호화 로직 식별
  3. 응답 본문 보존 — 8개 endpoint의 실응답 JSON을 파일로 저장해 스키마 검증

5. 검색 API 암호화 사양

검색 리스트 API 3개만 페이로드를 enc 필드 하나로 암호화 전송합니다. 나머지는 모두 평문. 키와 IV가 클라이언트 JS에 평문으로 하드코딩되어 있어 사실상 난독화 수준입니다 (목적은 자동 봇 1차 방어로 추정).

5-1. 클라이언트 코드 (난독화 해제)

// /_nuxt/e55fb8a.js 내부 (chunk size 2.1MB)
setEncDef: function(data) {
  return this.setEnc(data, "SKFJ2424DasfaJRI", "sfq241sf3dscs321")
},
setEnc: function(data, e, t) {
  return CryptoJS.AES.encrypt(
    data,
    CryptoJS.enc.Utf8.parse(e),                  // KEY
    {
      iv: CryptoJS.enc.Utf8.parse(t),            // IV
      padding: CryptoJS.pad.Pkcs7,
      mode: CryptoJS.mode.CBC
    }
  ).toString()
},
setEncParam: function(param) {
  return { enc: this.setEncDef(JSON.stringify(param)) }
},
searchDrctList: function(param) {
  return this.$AxiosBuilder
    .data(this.setEncParam(param))
    .build()
    .post("/bc/search/list/drct")
}

5-2. 암호화 사양

항목값
알고리즘AES-128-CBC + PKCS7
Key (UTF-8, 16바이트)SKFJ2424DasfaJRI
IV (UTF-8, 16바이트, 고정)sfq241sf3dscs321
입력JSON.stringify(searchParam)
출력 인코딩Base64 (CryptoJS 기본)
전송 형식{ "enc": "<base64>" }
응답 복호화 필요❌ 없음 (평문 JSON)

5-3. Node.js 재현 (참고용)

const crypto = require('crypto');
const KEY = Buffer.from('SKFJ2424DasfaJRI', 'utf8');
const IV  = Buffer.from('sfq241sf3dscs321', 'utf8');

function encKcarParam(param) {
  const c = crypto.createCipheriv('aes-128-cbc', KEY, IV);
  return c.update(JSON.stringify(param), 'utf8', 'base64')
       + c.final('base64');
}

// 호출 예 (Node 서버사이드, CORS 무관)
const enc = encKcarParam({ pageNo: 1, limit: 26, mnuftrCd: '001' });
const res = await fetch('https://api.kcar.com/bc/search/list/drct', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Origin':       'https://www.kcar.com',
    'Referer':      'https://www.kcar.com/',
  },
  body: JSON.stringify({ enc })
});
왜 "암호화가 아니라 난독화"인가: 키·IV가 클라이언트 JS에 평문으로 박혀 있고, IV가 고정이라 CBC의 의미도 상실됩니다. 진짜 보안이 아니라 봇 트래픽 1차 방어용 obfuscation입니다. K-Car 측이 키 로테이션을 자주 하지 않는 이유도 같은 맥락 — 키가 보호 대상이 아닌 셈입니다.

8. 데이터 품질 평가 — 중고차 수출 플랫폼 적합도

수출 플랫폼 필수 데이터K-Car 제공 여부비고
제조사/모델/세부등급✓ 완벽코드 + 한글명 모두
연식·제조연월·주행거리✓ 완벽prdcnYr, mfgDt, milg
판매가✓ 완벽만원·원 단위 모두 (prc, salprc)
VIN (차대번호)✓ 완벽수출 통관 필수, /bc/detail/gov/bas
차량 제원 (중량/치수/연비)✓ 완벽해외 등록 필수
사고/수리 이력✓ 부품별판금/교환 부품을 외관 10 + 프레임 26개로 세분화
옵션 (총 47종)✓ 완벽코드 + 한글명
차량 이미지✓ 360° × 72장해외 바이어 신뢰도에 결정적
색상✓ 완벽색상명 + 코드
최고출력·연료타입✓ 완벽해외 시장 사양 비교용

결론: 수출 플랫폼에 필요한 모든 데이터가 K-Car 응답에 이미 포함되어 있습니다. 추가 변환·정제만 하면 바로 바이어 화면에 노출 가능한 품질입니다.

9-2. (C) 비공식 호출의 구체적 리스크

  • 약관 위반 — K-Car 이용약관 + 저작권법 제93조(DB권) 침해 가능성
  • 개인정보 — 응답에 판매자 휴대폰·차대번호(VIN) 포함, 별도 수집·이용 동의 필요

  • IP/UA 차단 — 비정상 트래픽 패턴 감지 시 즉시 IP 차단
