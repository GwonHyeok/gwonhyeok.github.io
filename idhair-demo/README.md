# idHAIR 고객 상담 시스템 미팅 데모

크몽 엔터프라이즈 프로젝트 #226676의 의뢰서와 첨부 종이 설문지를 기반으로 만든 인터랙티브 프로토타입입니다.

## 데모 주소

- GitHub Pages: `https://ghyeok.io/idhair-demo/`
- 로컬: 저장소 루트에서 정적 서버를 실행한 후 `/idhair-demo/` 접속

## 미팅 권장 진행 순서

1. 상단의 `고객 설문`을 선택합니다.
2. 신규 고객 설문 5단계를 직접 진행합니다.
3. `관리자`로 전환해 전사 대시보드를 설명합니다.
4. 최근 설문에서 고객을 선택해 상담 상세와 동의 이력을 보여줍니다.
5. 통계 분석에서 지점·메뉴·두피·모발 데이터를 설명합니다.
6. 설문 관리에서 문항 편집과 버전 관리 방식을 설명합니다.
7. 지점, 직원·권한, 운영 설정 순으로 약 100개 지점 운영 구조를 설명합니다.

## 구현 화면

- 고객용 반응형 설문 5단계 및 제출 완료 화면
- 본사 통합 대시보드
- 고객·설문 목록과 고객 상세
- 기간·지점·문항별 통계 분석
- 설문 문항 편집기
- 지점 관리
- 직원·3단계 권한 관리
- 개인정보·백업·감사 로그 운영 설정

## 데모 성격

화면과 상호작용을 확인하기 위한 프런트엔드 프로토타입입니다. 표시되는 고객·지점·통계는 모두 예시 데이터이며 실제 개인정보나 운영 데이터가 아닙니다.
